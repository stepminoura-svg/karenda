- 添付 Excel のデータを変換スクリプトで再生成し、同梱カタログとバイト単位で一致。
- ドメインロジックの 6 テスト成功：年度境界・閏日・予定生成・重複・英検条件境界・カタログ件数・復元形式検証。
- Chromium の画面操作テスト成功：検索→追加→重複追加防止→履歴保存→カレンダー切替→不正日付拒否→履歴復元→生徒分離→英検検索→キャンパス検索。
- Electron 本体のテスト成功：起動、実ファイル保存、再起動復元、バックアップ JSON 出力/取込、PDF 生成、路線図の駅名検索・強調。
- 生成 PDF は A4 横 1 ページ。日本語とイベント表示を画像化して目視確認。
- 全 JavaScript の構文チェック成功。
- npm ci による再インストール成功。Node.js の標準プロキシを有効にして Electron をダウンロード。TLS・チェックサム検証は維持。
- Windows x64 ZIP をクロスビルド。Windows 実機での動作と印刷ダイアログ、署名・インストーラーは未検証。ZIP は署名なしの開発版。

画面テストは desktop IPC をモックし、別の Electron テストで実際の保存・PDF IPC を検証しています。自動テストは専用の一時保存フォルダーを使います。大学の公式募集要項との照合は検証対象外です。
